# Retail sales - SQL analysis
This project transform database in SQL to obtain certain information for futher marketing strategy

## Description
- Creating table for upload data from CSV file.
- Upload data from CSV file to created table "Sell"
- Removing rows from tables whose values ​​contain 'NULL'
- Checking which category brings the highest profits, broken down by buyer's gender and age
- Checking which category brings the highest profits and how these profits are distributed in a given category according to the buyer's gender and age

## Results

The highest profit 15 300 PLN, 4% of all Profit was recorded for men in the 'Beauty' category, in age group 20 - 25, 13 900 PLN (3% of all profit) for men in the ‘Electronic' category in age group Pensioners above 60 years old, 13 100 PLN for men in the ‘Electronic’ category in age group between 50 and 55 years old.

Recommendations
- Increasing the availability of bestsellers in the best-performing categories. In this database specific products names are not included, but it could be assume that for 20 – 25 years old men that could be some beard care accessories. For pensioners men in electronic category it could be hearing aids and electric bikes. 
- Increasing the average basket value (AOV) through cross-selling from this and other categories. For 20 – 25 years old men that could be combination of beard oil and beard brush.
